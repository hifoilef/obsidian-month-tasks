# 空库冒烟测试

此流程用于验证 Month Tasks 不依赖 Kanban、Tasks 或已有 `data.json` 也能正常启动。

1. 新建一个空 Obsidian 库，不安装 Kanban 或 Tasks 插件。
2. 在库内创建 `.obsidian/plugins/month-tasks/`，只复制 `main.js`、`manifest.json`、`styles.css`。
3. 确认插件目录内没有 `data.json`，然后在「第三方插件」中启用 Month Tasks。
4. 点击左侧日历图标打开月历，确认没有报错，并显示空月历和「待安排 0」。
5. 点击「+ 新建任务」，保存一条单日任务；确认默认笔记自动创建、月历立即显示任务。
6. 勾选该任务为完成，再取消勾选；确认笔记中的 `[ ]` / `[x]` 同步变化。
7. 右键任务，分别设置任务颜色和圆点标记；关闭并重新打开月历，确认两者仍在。
8. 在默认笔记手写一条无日期的 `- [ ] 待安排测试`，打开待安排栏并确认它出现；勾选后应消失。
9. 禁用、启用插件三次，再修改一条任务；确认界面只刷新一次且没有重复通知或控制台报错。

通过标准：以上操作均正常，插件目录生成有效的 `data.json`，且没有安装其他任务插件也可完整使用。
